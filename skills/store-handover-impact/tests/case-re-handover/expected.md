# 測試案例：中途再轉手（18 個月三個經營者）

**維度**：事件結構複雜化——**兩次易主**，同期 YoY 會整段跳過中間那一手
**分支**：事件2 整體✅✅／轉出方❌／接手方 **✅ 贏**；事件1 為 ❌❌
**資料**：`reg.csv`（自包含，**含 2025H2，是唯一模組 C 可執行的案例**）｜**擴展案例**

## 必過項

1. **必須自己發現有兩次異動**。prompt 只說「目前由乙豐經營」，`operator` 欄在 202507、202601 各換一次。**只做 H1 vs H1 的同期 YoY 會整段跳過甲興經營的那 120 台，而報告不會有任何地方顯示這個遺漏。**
2. **兩次異動分開歸屬**：A 店「還沒回到直營水準」（−10%）的缺口形成於**事件1**，把它記在乙豐頭上是錯誤歸因。
3. **兩個窗口都要報，不擇一**：事件窗口（P1→P2）+50% 回答「這次異動的效果」；YoY 窗口（P0→P2）−10% 回答「走完兩次後相對原始狀態」。**這是第四鐵則從空間口徑類推到時間口徑。**
4. **「崩盤」在這裡可用**——本案有月度資料且 202507 交接當月 33→22（−33%）、六個月未回補，**斷層可證**。用「退步」較保守也可接受，但要照列斷層事實。（對照：其他案例因斷層 ⬜ 一律禁用該詞。）
5. **累計窗口要明講「蘆竹區落後所屬桃園市」**（+8.57% vs +16.98%），且落後未易主的龜山區（+33.33%）。
6. **對照組污染 + 基準獨立性**：唯一同級對照組龜山區的量體 100% 來自轉出方直營；且桃園市＝蘆竹＋龜山，基準②內含目標市場本身。兩者都要申報。

## 參考數字（僅供對照，非判準）

## 這個案例挖出過什麼

**框架撐住了，沒有加規則。** 2/2 都自己判讀出兩次異動、分開歸屬、兩個窗口並列。

其中一份還多做了**扣除共同順風**：用未易主的龜山C店（+26.3%）當反事實基準，算出蘆竹B「等於只跟著順風走」、蘆竹A「超出順風 +28 台」——把 DiD 的精神用到經營者層級。並誠實檢查了這對判定的影響：「若保守地把 ①a 視為持平，①b 仍為正、量體較大、人均 +25%，**判定不翻轉**」。
