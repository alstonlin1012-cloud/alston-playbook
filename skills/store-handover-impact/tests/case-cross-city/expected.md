# 測試案例：接手方跨縣市（口徑分歧）

**維度**：事件結構複雜化——接手方的既有店分布在**目標縣市以外**
**分支**：整體 ✅✅ ／ 轉出方 ✅ ／ 接手方 ⚖️ ／ 標的 **超額成長**
**資料**：`reg.csv`（自包含）｜**擴展案例**（非每次必跑，見 README 分層）

---

## 情境（可直接貼給 agent，勿附下方預期結果）

> 現在是 2026 年 7 月。台中「中區A店」原為 GOGORO 直營，2025 年底轉給加盟商「宏運」經營。
> 主管要你評估：**這次易主，對各方分別造成什麼影響？**
>
> 資料：`tests/case-cross-city/reg.csv`
> **這是新資料源，skill 的 `domain-motorcycle.md` 不適用——依下面資料合約。**
>
> 資料合約（UTF-8、逗號）：`city` 縣市｜`area` 行政區（有分區的縣市才有值，其餘為 `_`）｜`ym` 年月｜`brand` 品牌｜`operator` 經營者（自有門市才有值）｜`store` 門市｜`qty` 領牌數。
>
> 事件：中區A店 2025 全期直營，2025 年底轉給「宏運」，2026 起宏運經營。未易主的店維持原經營者。
>
> 業務人數（含店長，資料檔沒有）：中區A店 5→6｜中區B店 4→5｜彰化X店 6→2｜西區C店 3→4｜彰化D店 3→4

## 預期判定（必須完全吻合）

| 視角 | 預期 |
|---|---|
| 整體市場・縣市層（台中市） | **✅ 好** |
| 整體市場・腹地層（台中中區） | **✅ 好（超額成長）** |
| 原經營方（直營） | **✅ 好** |
| 接手方（宏運） | **⚖️ 只是變大** |
| 標的（中區A店） | **超額成長** |
| 定調 | **易主未失敗，接手方尚未證明** |

## 必過項

1. **①a 用「全部既有店」，不因某店在縣市外而排除**：宏運既有店＝中區B（台中）＋彰化X（彰化）。判效率要涵蓋兩家，得 −33.3%。
2. **①a ＋ ①b 反向的處理**：①a −33.3%／①b +25.0%。**不得判贏**——彰化大盤持平（10,000→10,000），負值無市場可歸因；量體權重上負的（−250 台）也大於正的（+90 台）。
3. **標的做得好 ≠ 接手方贏**：中區A店是超額成長，但接手方仍是 ⚖️。這是「標的評語不可套到接手方」的鏡像版本（前幾個案例是反過來的）。
4. **對照組污染**：同級對照組（西區）唯一成員就是轉出方的西區C店。要說明污染方向（推高對照組→讓目標市場看起來更差）並做敏感度測試。
5. **第三層基準也可能被污染**：全域代理含彰化市，而彰化市同時有宏運與直營的據點。可改用**南投縣**（唯一無任何當事人據點的乾淨基準）交叉驗證。
6. **交接斷層 ⬜**，彰化X店最重只能用「退步」，不得用「崩盤」。

## 參考數字（僅供對照，非判準）

- 台中市市占 3.875%→4.833%（YoY +24.7%／+0.958pp）；中區 4.400%→5.727%（+30.2%／+1.327pp）
- 標的中區A 240→330（市占 YoY +25.0%）；既有中區B 200→300（+36.4%）；既有彰化X 300→50（**−83.3%**）
- 宏運版圖 500→680（+36.0%），移轉 330 台＝期末量的 48.5%
- 既有店同口徑人均 8.33→8.33（**0.0%，但那是量與人同時砍出來的**）

## 這個案例挖出過什麼

**它證明了一個「看似有洞、實際沒有」的地方——這個結論和「找到洞」一樣重要。**

框架寫「保留／既有據點要報全部據點口徑與縣市內口徑**兩個**」，但前六個案例裡**兩口徑全部重合**，那條規則等於從沒被測過。本案讓它們**方向相反**（縣市內 +36.4% vs 全部據點 −33.3%），本意是逼出「判定該用哪個」的分歧。

**結果 4/4 收斂**（初版 2 份 ＋ 刻意加大落差的尖銳版 2 份，即兩條路徑會導向 ✅ 與 ⚖️ 不同判定時）。所有分析者都一致用**全部據點口徑**判效率，理由也一致：判「接手方整體效率」本來就該涵蓋它手上所有的店。兩口徑並列是用來**描述成長**的，不是判定的分岔點。

> **不要為這個維度加規則。** 已驗證框架的既有寫法足夠。
