# 測試案例：市場衰退但接手方撐住（合成資料）

**分支**：整體市場 ✅✅ ／ 原經營方 ⚖️ ／ 接手方 **✅ 贏** ／ 標的**退步但市占上升**
**資料**：`reg.csv`（自包含，UTF-8 逗號分隔）

> 這個分支是 `tests/README.md` 標記「**最該補**」的那一個——**唯一該讚美接手方的衰退場景**，最容易被誤判成失敗。

---

## 情境（可直接貼給 agent，勿附下方預期結果）

> 現在是 2026 年 7 月。新竹「竹北A店」原為 GOGORO 直營，2025 年底轉給加盟商「宏達」經營。
> 主管要你評估：**這次易主，對各方分別造成什麼影響？**
>
> 資料：`tests/case-decline-acquirer-holds/reg.csv`
> **這是新資料源，skill 的 `domain-motorcycle.md`（台南案）不適用——依下面資料合約，不要硬套那份 domain。**
>
> 資料合約（UTF-8、逗號）：`city` 縣市｜`area` 行政區（新竹縣市有分區，其他縣市為 `_`）｜`ym` 年月｜`brand`（`GOGORO`／`競品`）｜`operator`（GOGORO 門市有值：`直營`／`宏達`）｜`store` 門市｜`qty` 領牌數。
>
> 事件：竹北A店 2025 全期直營，2025 年底轉給「宏達」，2026 起宏達經營。宏達B店（竹北區）為宏達既有店。新竹C、新竹D 為直營（東區），未易主。
>
> 業務人數（含店長，資料檔沒有）：竹北A店 5→5｜宏達B店 3→3｜新竹C店 4→4｜新竹D店 3→3

## 預期判定（必須完全吻合）

| 視角 | 預期 |
|---|---|
| 整體市場・縣市層（新竹縣市） | **✅ 好** |
| 整體市場・腹地層（竹北區） | **✅ 好（超額成長，贏過三層基準）** |
| 原經營方（直營） | **⚖️ 持平** |
| 接手方（宏達） | **✅ 贏** |
| 標的（竹北A店） | **退步**（絕對量 −15%）**且必須並陳市占 +13.3%** |
| 定調 | **不是三贏**（轉出方僅持平），但**明確不是易主失敗**。近似「品牌與接手方都贏了，差一格才是三贏」 |

## 必過項（這個案例專門擋這些）

1. **接手方判「✅ 贏」不是「⚖️」**：市場崩跌 25%，宏達**既有店市占 YoY +26.7%**、**新接店市占 YoY +13.3%**，兩個判準列同向為正。**在衰退市場中，跌得比市場少就是贏。**
2. **不得拿「絕對量在跌」否定市占在升的經營者**：宏達既有店台數 −5%、標的台數 −15%，全都在跌——但市場跌 25%。
3. **拒用經營者口徑人均當效率證據**：宏達經營者口徑人均 +31.2%，是併進高產能店的**組合效應（移轉污染）**，不是效率改善。要用就用同口徑（既有店 −5.0% vs 市場 −25.0%）。
4. **標的用「退步」但強制並陳市占**：只寫「退步」不寫 +13.3%／+0.40pp 就是紅旗。**「退步」描述的是量，不是相對競爭力。**
5. **原經營方判 ⚖️ 不是 ❌**：保留店台數 −25.7% 看起來很慘，但**判準看市占**——東區市占 YoY +2.86%（東區大盤 −27.8%）。沒失血，也沒變強。
6. **⚖️ 不可用於整體市場那格**：兩層都是二值 ✅。
7. **交接斷層填 ⬜**：缺 2025H2（正是交接窗口），不得宣稱「無斷層」。可陳述「接手首月未崩量」，但那不等於無斷層。
8. **同區虹吸可證為無**（直營 2026 在竹北區據點 0、量 0）；**跨區虹吸 ⬜ 不可排除**，不得宣稱「本案沒有虹吸」。
9. **所有 ✅ 都要註明是「份額意義上的贏」**：絕對量全面在縮，市場續跌則份額紅利無法轉成營收。

## 已知的判定彈性（觀察中，尚未構成分歧）

**原經營方那一格是本案唯一有解釋空間的格子**，而它正好決定這案算不算「三贏」：

- 寬鬆讀法：「市占 YoY 方向為正即 ✅」→ 保留店 +2.9% 為正 → **✅**，定調變「三贏」。
- 框架讀法：視角 2 的判準是「成長，**且是該地成長主引擎**」→ +2.9% 遠落後腹地（+16.7%）與縣市（+9.0%）→ **⚖️**。

**實測 2/2 都採框架讀法判 ⚖️**，其中一份還主動揭露了這個彈性。目前**不構成分歧，故不改框架**——但若日後出現 agent 判 ✅，那就是視角 2 判準寫得不夠緊，屆時要修的是視角 2，不是這個案例的預期值。

## 這個案例挖出過什麼

**史上最大分歧**：首次跑 3 個 finder，同一份資料產出**三種不同判定**（接手方 ⚖️／✅／⚖️，原經營方 ❌／⚖️／⚖️）。

診斷結果是**一個病、四處症狀**：框架的第二鐵則要求用相對市占判「好不好」，但視角 2、視角 3 的判準卻寫成絕對量——**在成長市場兩者同向，看不出來；一進衰退市場就爆開。**

修正後 3/3 收斂到 ✅ 贏。

**接著這個修正又暴露第二個洞**：效率證據的優先序只寫了「既有據點」，漏了「新接據點」，與第四鐵則不一致。回歸測試中 `case-synthetic-nonwin` 的兩個 agent **靠回頭引用第四鐵則自行補上**才判對——框架自相矛盾時 agent 挑了對的那半邊，是運氣不是設計。**測試通過 ≠ 框架完備。**
