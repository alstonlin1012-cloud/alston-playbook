## 情境（可直接貼給 agent，勿附下方預期結果）

> 現在是 2026 年 7 月。台南「東區A店」原為 GOGORO 直營，2025 年底轉給加盟商「弘昌」經營。
> 主管要你評估：**這次易主，對各方分別造成什麼影響？**
>
> 資料：`tests/case-handover-failed/reg.csv`
> **這是新資料源，skill 的 `domain-motorcycle.md` 不適用——依下面資料合約。**
>
> 資料合約（UTF-8、逗號）：`city` 縣市｜`area` 行政區（有分區的縣市才有值，其餘為 `_`）｜`ym` 年月｜`brand` 品牌｜`operator` 經營者（自有門市才有值）｜`store` 門市｜`qty` 領牌數。**欄位實際有哪些值，請自己盤點，不要假設。**
>
> 事件：東區A店 2025 全期直營，2025 年底轉給「弘昌」，2026 起弘昌經營。弘昌既有店：南區X店。直營未易主的店：東區C店、南區D店。
>
> 業務人數（含店長，資料檔沒有）：東區A店 5→4｜南區X店 4→3｜東區C店 3→3｜南區D店 3→3

## 預期判定（必須完全吻合）

| 視角 | 預期 |
|---|---|
| 整體市場・縣市層（台南市） | **❌ 壞** |
| 整體市場・腹地層（東區） | **❌ 壞**（輸給全部三層基準） |
| 原經營方（直營） | **❌ 壞** |
| 接手方（弘昌） | **❌ 退步** |
| 標的（東區A店） | **退步**（**不是「崩盤」**，見必過項 4） |
| 定調 | **易主失敗** |

## 必過項（這個案例專門擋這些）

1. **接手方判 ❌**：弘昌**含移轉後版圖仍縮**（260→220，−15.4%）。這是刻意設計的——移轉進來的東區A店（100 台）**沒有**補回既有店的崩跌（南區X −140 台）。若把基期算成店組口徑（560）會得到 −60.7%，方向相同但口徑不同，不得混用。
2. **不得把帳全記在接手方頭上**：**未易主、未減人的直營南區D店同期市占 YoY 也是 −15.6%**，台南存在跨經營者的共同病因。正確寫法是「弘昌跌得比所有人都深（−58.0%／−69.7% vs 直營 −45.5%／−15.6%）——**易主是加重，不是全部**」。
3. **「市場在跌別怪接手方」不適用**：台南**全品牌大盤 +10%**，同期嘉義 +2.4%、高雄 +0.3% 的 GOGORO 市占持平微升——**是 GOGORO 在台南單獨失血**，不是市場衰退。
4. **標的用「退步」不得用「崩盤」**：「崩盤」的定義帶交接斷層舉證要求，而 2025H2（交接窗口）完全缺資料 → 模組 C 是 ⬜。可以說「2026H1 已在低檔止穩」，**不能說「交接崩量」**。即使量掉了三分之二也一樣。
5. **品牌內佔比上升 ≠ 版圖擴大**：弘昌佔台南 GOGORO 比重 32.5%→53.7%、店數 1→2，看起來在擴張——但那是**分母崩塌的稀釋效應**（台南品牌總量 800→410）。版圖一律看量體。
6. **同區虹吸可證為無**：直營在東區**仍有**東區C店，但 C 店同期 100→60 也在跌，**沒有承接 A 店流失的 240 台**。跨區虹吸仍 ⬜。
7. **對照組污染**：唯一的同級對照組南區裡有弘昌既有店 X，X 自身的崩跌壓低了南區。剔除後只看直營南區D店（−15.6%），目標市場輸得更多——**判定不翻轉**。

## 參考數字（僅供對照，非判準）

- 台南市市占 4.00%→1.86%（YoY −53.4%／−2.14pp），全品牌大盤 **+10.0%**
- 東區市占 4.00%→1.45%（YoY −63.6%／−2.55pp），輸給南區、台南市、其他縣市三層
- 弘昌版圖 260→220（−15.4%）；既有店 X 市占 YoY −58.0%；新接店 A −69.7%
- 標的東區A 300→100（−66.7%），人均 10.00→4.17（−58.3%）
- 直營保留店 240→190（−20.8%），東區C 市占 YoY −45.5%、南區D −15.6%

## 這個案例挖出過什麼

2/2 完全收斂。最有價值的是兩份報告都**主動擋住了歸因謬誤**——在一個所有人都在跌的市場裡，正確的結論不是「弘昌搞砸了」而是「**存在共同病因，且弘昌在其上又額外跌得更深**」。兩份都給出同一個行動建議：**先查台南層級的共同因素，再談對加盟商問責。**

另外，「崩盤」的證據門檻是其中一份自己推出來的（框架當時只在定義裡寫「交接期出現斷層且未回補」，沒明講斷層 ⬜ 時不得使用）——**事後補進框架**。
