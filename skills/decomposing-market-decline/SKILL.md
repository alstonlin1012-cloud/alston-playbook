# 分解市場量的變化：人口 vs 行為

## Overview

任何「量」都可以寫成兩個因子：

```
量 L ＝ 人口 P × 人均強度 R          （R = L / P，滲透率）
```

量在跌，只有兩種可能：**人變少了**（外生，不可介入）或**每個人買得少了**（內生，可介入）。
這兩者的商業意涵完全相反 —— 前者要調整規模與時程，後者要修產品與定價。**不分開就是廢話。**

這份 skill 是把「量在跌」變成一個可證偽、可重現的分析流程。

## When to Use

- 領牌數／銷量／註冊數／入學人數／載客數在衰退或成長，要歸因
- 有人主張「年輕人不再買 X 了」，要驗證是偏好轉移還是分母縮水
- 要推估基本盤的長期軌跡與拐點年
- 判斷行銷／產品投入能不能逆轉趨勢

**不適用**：無法取得對應人口分母的量；分母群體定義不穩（大量流動人口且無法估計）；只想看短期波動（分解是十年尺度的工具，不是月報）。

## 八步流程

### 1. 先畫因果結構，再碰資料

畫一張圖：這個量是怎麼被決定的。目的只有一個 —— 把驅動力切成**外生**（人口、法定年齡、四十年前就決定的出生數）與**內生**（產品、價格、通路、替代品）。

同一筆量常有**多種切法**（按「誰在買」切、按「為何買」切）。切法之間**不可相乘**，會重複計算。明寫哪一種切法本次做得出來、哪一種需要現有資料沒有的欄位。

### 2. 鎖口徑，寫進交付物

- 分子分母必須是**同一群人**。分子排除法人／機構，分母就不能含法人。
- **不混用不同來源的量**。廠端出貨 ≠ 監理端掛牌 ≠ 通路 POS。口徑不同，混用製造假訊號。
- 選定一種後，全程只用它，不「交叉驗證」。

### 3. 動手前寫死證偽標準

在看到任何數字**之前**，寫下三種判準與對應行動：

| 判準 | 形式 |
|---|---|
| 主因判準 | 人口效果貢獻 < 20% / 20–50% / > 50%，各自的結論與後續行動 |
| 值不值得做判準 | 目標族群佔總量的比例低於 X% 時，據實報告「這族群已是邊緣」並轉向 |
| 訊號真假判準 | 觀察到的差距必須大於已知偏誤上限，否則報「無法區辨」 |

**理由**：已經在假說上投入大量論證後，會有強烈動機去解釋「為什麼我原本的假說還是對的」。這叫 HARKing（事後合理化）。等看到數字再定判準，判準就沒有約束力。

門檻一旦寫定，**不得因為範圍擴大而事後上調或下調** —— 那等於換一把更寬鬆的尺，必然「通過」。

### 4. 對齊分組刻度

年齡組、區域、時間粒度，分子與分母必須用**同一套切法**。人口統計是 5 歲一組、業務資料是 `18-20 / 21-25`，就得先把人口重新分組對齊業務資料，不是反過來。刻度不齊算出來的滲透率是假的。

### 5. Shift-share 分解，基期終期一律取三年平均

```
ΔL = R₀·ΔP        人口效果
   + P₀·ΔR        滲透率（行為）效果
   + ΔP·ΔR        交互作用
```

採 Laspeyres 慣例（以基期為權數），交互項單獨列出，不併入任一方。

**基期與終期一律取三年平均，不可用單一年度端點。** 政策脈衝（補助、法規上路前搶購、稅制變動）會讓單一年度偏離常態數十個百分點，拿脈衝年當基期會把政策效果誤記成行為變化，**結論可以完全翻轉**。

貢獻比例一律取絕對值比大小：

```
人口效果貢獻 = |人口效果| ÷ ( |人口效果| + |滲透率效果| )
```

這回答「兩股力量誰比較大」，不是「誰造成了淨變化」—— 兩者方向相反時，淨變化會騙人。

實作見 `shift_share.py`。

### 6. 分清「世代」與「年齡層」

追蹤「2015 年的 20 歲」到「2025 年的 20 歲」**不是同一群人**。要看同一群人，必須沿對角線走（2015 的 20 歲 → 2025 的 30 歲）。

- 想問「這個年齡格子的表現變了嗎」→ 橫切年齡層
- 想問「這群人的行為變了嗎」→ 沿世代追蹤

混用會把人口組成變化誤讀成行為變化。

### 7. 聚焦上游入口流量

長期基本盤由**新進場者**決定（滿法定年齡人數、新生入學數、新設戶數），不是總量。上游是外生且已鎖定的 —— 十八年後的 18 歲人口，今天就已經全部出生了。這是整份分析裡唯一能高信心外推的東西。

如果資料看不出「首次購買」，就得接受一條**代換假設**（如「18–25 歲的購買 ≈ 首購」）。此時必須：

1. 明寫這是假設不是資料
2. 拆成**強假設層**與**弱假設層**分開報告，不只報合計
3. 不得反過來宣稱「本研究測得了首購」
4. 兩層的分歧本身就是訊號（同步下滑＝人口效應；年輕層跌而年長層撐住＝行為遞延）

### 8. 交付物必帶三段

- **範圍界定** —— 哪些是已決定不做的，寫明「非待辦」，避免讀者與未來的自己重啟辯論
- **已知限制** —— 每條代換假設、每個偏誤來源及其量級上限
- **重現指令** —— 從原始檔到圖表的完整指令序列

## Quick Reference

| 症狀 | 對應步驟 |
|---|---|
| 「年輕人不買了」的主張 | 5（分解）+ 6（世代） |
| 結論對基期年很敏感 | 5（三年平均） |
| 滲透率算出來怪怪的 | 4（分組對齊）+ 2（口徑） |
| 想外推未來十年 | 7（上游入口流量） |
| 團隊在爭論結果代表什麼 | 3（事前判準沒寫） |
| 區域／族群差異是否為真 | 3（判準三，偏誤上限） |

## 反模式

| 反模式 | 為什麼錯 |
|---|---|
| 用單一年度當基期 | 政策脈衝主宰，結論可翻轉 |
| 殘差直接命名為「行為效應」 | 殘差裝的是所有沒被建模的東西，包含口徑錯誤。要用白話描述算的是什麼 |
| 把兩種切法相乘 | 同一筆量的兩種切法，相乘＝重複計算 |
| 混用出貨量與掛牌量交叉驗證 | 口徑不同，差異是定義造成的，不是訊號 |
| 看到結果才寫判準 | HARKing |
| 只報合計數 | 掩蓋強假設與弱假設的差別 |
| 把「不分析」寫成「不存在」 | 暫不分析的因子（季節性、政策）仍在影響數字，必須標註時點 |
| 每人買車台數直接外推 | 那是人均強度，不是傾向；外推前要先檢查它本身穩不穩 |

## Red Flags — 停下來

- 「先看看資料長怎樣再決定要驗什麼」→ 步驟 3 沒做
- 「用 2015 當基期比較乾淨」→ 那年是不是政策年？查
- 「殘差是行為效應」→ 換白話重寫
- 「這個族群佔比比預期低，但我們已經投入很多了」→ 判準二存在就是為了這一刻，據實報告
- 「拿另一份資料交叉驗證一下」→ 先確認口徑相同，否則不要
- 「同一年齡層十年前後比較」→ 你比的不是同一群人
