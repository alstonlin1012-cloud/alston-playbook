# 假設反證法 Playbook

> 業務／管理層丟一個直覺假設過來（「某指標過了某門檻就會跳升」「某區塊衰退是結構性」「新品上市會救銷量」），分析師的任務不是去「證實」它，而是**走完一條反證路徑**，看它站不站得住。多數時候假設會被修正或推翻，少數時候會被加強並量化。

## 情境（什麼時候拿出來用）

- 業務／管理層給你一個單一指標＋一個直覺詮釋（例：「這週 X 掉是因為 Y」）
- 給你一個經驗門檻（例：「過 N 就會跳」）
- 給你一個結構性歸因（例：「南部整體衰退」「新車救得回」）
- 任何時候別人用「一定是」「就是」「因為」解釋一組數字

## 核心原則

1. **先懷疑問題本身**：很多時候「問題」是量尺偏移造成的錯覺（門檻偏高、基期異常、口徑錯）。
2. **多視角交叉**：同一個現象從不同時間／空間／族群視角會給出不同答案，**選錯視角就得出錯結論**。
3. **可歸因雜訊優先排除**：日型、工作日、季節、天氣、檔期、資料品質——先把這些解釋掉，剩下的才是真訊號。
4. **散佈度檢驗結構假設**：「整體衰退」的假設需要大多數子單位同步，看到 3 升 7 跌就該撤回。
5. **假設演化要留紀錄**：每一次推翻／修正都寫下來，別偷偷換結論。

## 四層反證框架

### Layer 1 — 問題本身是真的嗎？

- 把假設裡的門檻、基準、量尺拉歷史序列看
- 檢查命中率、分布、常態波動範圍
- **若門檻命中率本來就 <50%，「這週沒達到」不是問題，是常態**
- **若數字落在歷史 ±1σ 內，直覺的「異常」是雜訊**

### Layer 2 — 掉／漲集中在哪裡？

拆到看得出集中度：

- **時間維度**：WoW／MoM／同一星期幾比／同一月份比
- **空間維度**：全國 → 區域 → 單位；絕對值排序 + 百分比排序各看一次
- **族群／類別維度**：產品線、通路、客群、產業垂直
- **單位產能視角**（排除「店多所以總量多」錯覺）：
  ```
  per_unit = Σ指標 / Σ(單位數 × 時間)
  ```

### Layer 3 — 可歸因的雜訊先排除

依序 rule out：

1. **日型 / 工作日 / 季節**：農曆、節假、營業日數變動
2. **產能變動**：單位開張／關閉／改制
3. **外生變數**：天氣、政策、公衛、競品動作（有資料就 JOIN，用還原公式）
4. **檔期／活動**：促案、campaign、新品上市日
5. **資料品質**：NULL 政策、口徑變動、系統切換

每一步排除完要重算指標，看剩多少。

### Layer 4 — 殘差還成立嗎？

- 全部排除完的殘差回到均值 → 假設**被雜訊完全解釋**，收工
- 殘差仍偏離 → 進入深挖
  - 鄰近單位同步？→ 區域／結構性因素
  - 單一單位異常？→ 個體問題（人／點位／管理）
  - 時序累進？→ 趨勢問題
  - 散佈分歧？→ **撤回結構性假設**

## 三種時間視角（都跑一遍再交叉）

| 視角 | 用途 | 常見陷阱 |
|------|------|---------|
| **WoW 單週比** | 找短期異常 | 前一週是異常高峰，造成假跌 |
| **月均 / 季均** | 找中期趨勢 | 被單週極端值拖動 |
| **週序列（事件標註版）** | 最平衡 | 需手動標註天氣／檔期才好讀 |

**原則**：三個視角給出相同結論才成立。給出矛盾結論的話，先問自己基期是不是乾淨的。

## 空間 / 族群視角

- **絕對值排序** — 找貢獻最大的掉幅／漲幅來源
- **百分比排序** — 找異常但基數小的子群
- **單位產能排序** — 排除基數影響，看真實「單位強度」
- **散佈度** — 子群是否同向？同向比例 = 結構性假設的強度

## 常見陷阱清單

| 陷阱 | 校正方式 |
|------|---------|
| 用一個偏高門檻當常態 | 先驗證門檻的歷史命中率 |
| 用 WoW 單週對比 | 檢查前一週是不是異常高峰 |
| 用月均看中期 | 剔除極端週（豪雨／大檔期）再重算 |
| 百分比排序前排都是小基數 | 加絕對值門檻（例：基數 > N）過濾 |
| 整體指標直覺 | 拉漏斗底端交叉看 |
| 總量 vs 單位均 | 兩個都看，確認是「人多」還是「人均強」 |
| 看到「全部下跌」就認結構性 | 看散佈，3 升 7 跌就撤回 |
| 把 NULL 當零 | 檢查 NULL 的分布，可能是追蹤缺漏不是真零 |
| 門檻假設 | 不要只看平均，要看低流量桶是不是真的近零 |

## 決策樹

```
假設進來
├─ 問題本身是真的嗎？
│  ├─ 門檻命中率 <50% → 門檻偏高，不是問題
│  └─ 落在歷史 ±1σ 內 → 雜訊，不是問題
├─ 掉／漲集中在哪？
│  ├─ 全面同步 → Layer 3 排除雜訊
│  └─ 集中在少數子群 → 直接進 Layer 4
├─ 可歸因雜訊排除後
│  ├─ 殘差回均值 → 完全解釋，收工
│  └─ 殘差仍偏離
│     ├─ 鄰近同步？→ 結構性候選
│     ├─ 單一離群？→ 個體問題
│     ├─ 散佈分歧？→ 撤回結構性假設
│     └─ 時序累進？→ 趨勢問題（追早期訊號）
└─ 寫結論：假設 ✅／⚠️／❌ ＋ 修正版
```

## 給下游的交付：三句話總結

**鐵則**：報告寫三句結論，照下面句型：

- **短期**：{時點} {現象}。{外生變數} 解釋 {比例}。
- **中期**：{時點對比} 看似 {變動}，但 {校正方式} 後只 {真實變動}，屬 {評價}。
- **問題源**：{最乾淨訊號的子群} 是本輪最明確的問題；{其他候選} 不能支持 {原假設}。

## 真實失敗案例（去識別化）

### 案例 1：門檻偏高造成假問題
業務指出「某週單日指標未達 X」。拉歷史同期後發現，過去 10 週中只有 2 週達到 X，命中率 20%。**X 本來就不是「正常線」，而是偏高標**。原假設直接退回：這週沒達到不是問題。

### 案例 2：月均視角 vs 週序列視角給出不同結論
月均視角顯示某區域 M 月比 M-2 月掉 27%，看似結構性衰退。改週序列視角，剔除 M 月中含極端外生事件（連續豪雨）的兩週後，實際只掉 7%，屬正常波動。**原結論「區域結構性衰退」被推翻**。

### 案例 3：散佈分歧撤回結構性假設
假設是「某縣市因政策退場，整區衰退」。拉該縣市全部 11 家單位看，實際是 3 升 7 跌 1 疑停業，分布分歧。**撤回結構性假設**，改為「單位 A 連續走弱＋單位 B 疑似停業」兩個個體問題。

### 案例 4：外生變數還原後假設仍成立但訊號變小
原假設是客流掉點。排除日型、開店數、天氣（JOIN 外生表還原）、檔期後，仍有一個區域殘差未解釋，且單位產能排在同層最弱。**假設修正為：這個區域有結構性弱化，但不是全國問題，優先追這一塊**。
