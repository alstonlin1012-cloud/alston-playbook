# 人口 × 滲透率拆解法

> 任何市場量衰退都有**兩種完全不同的成因**：母體（人口 / 基數）變化、行為（滲透率 / 人均傾向）變化。這兩者的商業意涵**相反**：母體效果是外生、不可逆；滲透率效果是內生、可介入。分不清就會做出完全錯誤的策略。

## 情境（什麼時候拿出來用）

- 市場量（領牌、銷售、使用量、註冊量…）在衰退
- 老闆問「我們產品是不是有問題」
- 要決定「加碼行銷 vs 退場轉型」
- 要向董事會解釋為什麼業績走下坡
- 分析任何「跨時期總量變化」的來源

## 核心主張

**衰退的因只有兩類**，分析的任務是量化兩者佔比：

| 成因 | 機制 | 商業意涵 | 可介入性 |
|------|------|---------|---------|
| **母體效果** | 這個族群的人變少了 | 外生 | ❌ 不可介入 |
| **滲透率效果** | 同族群的人買得比以前少 | 內生 | ✅ 產品／定價／通路可介入 |

**鐵則**：兩者比例決定行動方向。分不清就會「產品沒問題，加碼 100M 行銷」或「市場要退場，砍產線」這種誤判。

## 數學拆解

對每個族群 g（年齡／地區／客群類別），令：
- `L` = 量（領牌 / 銷售 / 使用量）
- `P` = 母體（人口 / 基數）
- `R` = L/P（滲透率 / 人均傾向）

從基期 0 到終期 1：

```
ΔL = R₀·ΔP        ← 母體效果（人變少所以買少）
   + P₀·ΔR        ← 滲透率效果（人沒變但買得少）
   + ΔP·ΔR        ← 交互作用
```

**三項分別回答**：
- 母體效果：若滲透率不變，單純人變少造成多少 ΔL
- 滲透率效果：若人數不變，單純行為改變造成多少 ΔL
- 交互：兩個同時變的高階項（通常小）

**好處**：三項**可加**、全部有實際單位、報告好讀。

## 基期與終期的選擇（最大坑）

**規則**：**兩期都取多年平均**（例：三年平均），不用單一年度。

### 為什麼

量化市場常受**政策脈衝**主宰：補助上路、法規截止、新品大規模鋪貨、公衛事件、節慶錯位。單一年度可能是脈衝年或脈衝前年，拿它當基準 = 把政策效果誤記成結構變化。

**真實案例**：某市場 2017 年有汰換補助讓量從 70 萬跳到 100 萬（+42%），2020 年法規上路前搶購衝到 104 萬。若拿 2015 當基年：

- 2015 的 70 萬是「補助前常態」
- 2018 的 100 萬是「補助當年」
- 單年比會把 +42% 都記成「滲透率提升」—— 錯

**改用三年平均**（基期 2015-2017、終期 2023-2025）後，政策脈衝被平均掉，剩下的是真實結構變化。

### 怎麼挑多年期

- 平均年數：3-5 年（夠平均脈衝、不夠太長以致混入早期結構）
- 兩期間隔：要夠長看出結構變化，例：隔 8-10 年
- 避開大型外生事件的中心（例：某年疫情）

## 族群切分（cohort）

**不能**只算整體。要**按族群分別算**，再匯整。

### 常見切法

| 切法 | 用途 | 常見坑 |
|------|------|-------|
| **年齡層** | 看代際差異（20s、30s、…） | 老齡族群人口成長 + 滲透率下降可能相互抵銷 |
| **地區** | 看區域結構 | 地區人口移動要處理 |
| **性別 × 年齡** | 更細結構 | 樣本變薄 |
| **族裔／國籍／教育** | 客群結構 | 隱私／可取得性 |

**鐵則**：族群是可比單位——跨期要是「同一族群的定義」，否則比的是不同東西。

## 解讀規則

### 規則 1：看「可解釋變化」佔比

- **可解釋變化** = 母體效果 + 滲透效果（不含交互）
- 母體效果佔可解釋變化 > 70% → 衰退**主要是外生**，產品端不是問題
- 滲透效果佔 > 70% → 衰退**主要是內生**，產品端出問題
- 兩者 40-60% 之間 → 混合，兩線都要動

### 規則 2：「滲透率變了但量沒變」的族群要單獨看

**例**：某族群人口成長很大，滲透率下滑一些，兩者抵銷。
- 滲透率下滑可能是**過度曝險**（市場飽和）—— 常態現象
- 或是**競爭力下降** —— 要追查
- 單看 ΔL 看不出來，需看滲透率變化

### 規則 3：「量在漲但滲透率在跌」的族群

**例**：高齡族群人口大漲（+N 萬人）、滲透率下跌（-M%）。
- 若人口效果 > 滲透效果 → 量仍漲
- 若這是高齡族群的常見模式（騎車生命週期尾端）→ 標註「屬正常，不列追查」
- 要跟歷史同族群比才知是否正常

### 規則 4：「量沒變但滲透率上升」的族群

**例**：中年族群人口在減少，但買得更積極，抵銷掉。
- 這是**內生成長訊號** —— 產品抓到這一族
- 值得單獨查是什麼帶動的

## 商業結論模板

### 結論 A：母體效果佔比高
```
XX% 的衰退是因為「這個年齡層的人變少了」—— 這是外生的、幾十年前就決定的。
產品、行銷、通路都無法逆轉。
建議：市場退場規劃 / 轉向成長中的族群 / 保留現有份額。
```

### 結論 B：滲透效果佔比高
```
XX% 的衰退是因為「同族群的人買得比以前少」—— 這是行為改變。
可能來自替代品、價格、產品老化、通路萎縮。
建議：產品線 review / 通路 review / 定價策略 / 替代品分析。
```

### 結論 C：混合
```
母體佔 X%、滲透佔 Y%。
母體那部分不能逆轉，滲透那部分可追查。
建議：先放棄母體那部分的敘事（別跟董事會說加碼能救），聚焦滲透那部分的介入。
```

## 常見陷阱

| 陷阱 | 症狀 | 校正 |
|------|------|------|
| 單一年度當基期 | 把政策脈衝記成滲透率提升 | 多年平均 |
| 不分族群 | 正反抵銷看不出來 | 按年齡／地區切 |
| 用銷售量代替領牌 | 口徑不同（出貨 vs 掛牌） | 定好口徑不要混 |
| 把法人混進個人 | 滲透率算錯 | 排除法人 |
| 「滲透率下降 = 產品問題」 | 高齡族群正常現象也被追查 | 比對歷史同族群 |
| 「人口下降 = 衰退不可逆」 | 滲透率有空間時不追查 | 兩者都算、看比例 |
| 交互項忘標 | 加減不平 | 寫在表上 |
| 跨期族群定義變了 | 比的不是同一東西 | 族群邊界固定 |

## 真實案例骨架（去識別化）

### 案例 1：84% 外生 → 行動方向大改
原始結論：「某市場領牌數連續衰退，產品有問題，加碼行銷」。
拆解後：84% 衰退來自母體效果，滲透率幾乎沒動。
**真相**：產品沒失去吸引力，是這個年齡層的人變少了。
**行動大改**：停止加碼行銷（救不回）、改轉向成長中的族群。

### 案例 2：單年基期把政策脈衝記成結構變化
原分析用某年當基期，結論「滲透率十年上升 40%」。
改用三年平均基期後，滲透率實際只上升 5%，大部分 +42% 是**補助脈衝**造成。
**原結論大翻車**：「產品大幅成長」改成「市場穩定、政策推一把」。

### 案例 3：中年族群抵銷機制
某族群人口 -5%，滲透率 +8%，量微增。
**單看量**：這族群沒事。
**拆解後**：滲透率 +8% 是**內生成長訊號** —— 產品抓到這一族。
**行動**：單獨 deep-dive 什麼帶動的，複製到其他族群。

### 案例 4：高齡族群滲透率下滑屬正常
某族群人口 +N%，滲透率 -M%。乍看是問題。
比對歷史同族群：過去 20 年高齡族群滲透率都在下滑，屬騎車生命週期尾端。
**行動**：標「屬正常、不列追查」，避免浪費分析資源。
